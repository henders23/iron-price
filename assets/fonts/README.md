# Fonts

Latin subsets of the three typefaces used by the title and frontier map
screens. They are vendored so the static build renders correctly with no
network access.

| File                                 | Family          | Source                                            |
| ------------------------------------ | --------------- | ------------------------------------------------- |
| `cinzel-latin-var.woff2`             | Cinzel 400–900  | https://fonts.google.com/specimen/Cinzel          |
| `im-fell-english-latin.woff2`        | IM Fell English | https://fonts.google.com/specimen/IM+Fell+English |
| `im-fell-english-italic-latin.woff2` | IM Fell English | https://fonts.google.com/specimen/IM+Fell+English |
| `jost-latin-var.woff2`               | Jost 200–400    | https://fonts.google.com/specimen/Jost            |

All three are licensed under the SIL Open Font License 1.1, which permits
bundling and redistribution with an application. Declarations live in
`src/screens.css`.
